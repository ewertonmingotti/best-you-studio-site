O que é o Be Run Club

O Be Run Club é a comunidade de corrida da Best You. Da caminhada à maratona, aqui você encontra gente que compartilha a mesma paixão pela prática, motivação em grupo e o pertencimento que só uma comunidade de corredores de verdade oferece.

Para quem quer correr, caminhar, treinar para a primeira prova ou simplesmente se mover com companhia — não importa o ritmo, importa começar.
